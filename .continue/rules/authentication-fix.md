description: Когда есть проблемы с аутентификацией между frontend и backend
  приложениями Django, используй прямой доступ к ORM вместо API-вызовов. Это
  работает потому что оба приложения используют одну и ту же базу данных и
  сессионную систему.
alwaysApply: true
---

Используй прямой доступ к базе данных вместо API-вызовов для аутентифицированных операций. Это устраняет проблемы с CSRF-токенами и сессионными куками между frontend и backend приложениями.
